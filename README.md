# Algoritm-Unumdorlik-Tahlili-Big-O-Notatsiyasi-
Algoritm Unumdorlik Tahlili (Big O Notatsiyasi)
📋 Vazifa sharti: Turli Big O murakkabliklariga ega funksiyalarni yozib, ularning ishlash vaqtini solishtiruvchi tahlil tizimi yarating. 1-qism: Funksiyalar yozing (har biri uchun Big O izohida ko'rsating): - O(1): massiv ichidan birinchi elementni qaytaruvchi funksiya - O(n): massivdagi maksimal elementni topuvchi funksiya - O(n²): massivda juft elementlarni topuvchi (ikki halqali) funksiya - O(log n): Binary search funksiyasi - O(n log n): Merge sort funksiyasi 2-qism: Vaqt o'lchash: - performance.now() bilan har bir funksiyani o'lchang - n = 100, 1000, 10000, 100000 uchun ishlash vaqtini jadvallang 3-qism: Natija tahlili: - Qaysi funksiya qanday o'sish grafigini ko'rsatadi? (konsol yoki jadvalda)

 Talablar
• Kamida 5 ta turli Big O murakkablikdagi funksiya yozilgan bo'lsin
• Har bir funksiyaning Big O izohi kodda bo'lsin
• performance.now() bilan vaqt o'lchangan bo'lsin
• n = 100 dan 100000 gacha bo'lgan 4 ta o'lcham sinab ko'rilgan bo'lsin
• Natijalar jadval yoki tuzilgan format bilan konsolga chiqarilgan bo'lsin
• O(1) va O(n²) ning farqi aniq ko'rinishi kerak

🛠 Ishlatiladigan konstruktsiyalar:
performance.now(); console.table(); for..of; while;
// O(n) - chiziqli murakkablik
